# Шаблон статического сайта (RSMA → любой проект)

Статический сайт на чистом HTML/CSS/JS без сборщика. Весь «частный» контент
(название компании, реквизиты, контакты, соцсети, тексты, тарифы, юр. текст)
вынесен в JSON и подставляется в шаблоны в браузере.

## Структура

```
index.html                        главная (шаблон)
More_information/index.html       «Подробнее» — 3D-модели, эксперименты, галерея
Tariff/index.html                 тарифы + форма заявки
Terms_of_use_of_the_site/index.html  правила пользования сайтом
data/
  site.json                       ГЛОБАЛЬНОЕ: компания, реквизиты, проект, меню, соцсети, футер, meta
  home.json                       контент главной
  about.json                      контент страницы «Подробнее» + список картинок галереи
  tariffs.json                    таблицы тарифов + тексты формы
  terms.json                      текст соглашения (сгенерирован из исходной страницы)
js/
  data.js                         мини-движок шаблонов + загрузка JSON (нужен на каждой странице)
  main.js                         общее: бургер, плавный скролл, анимации, модалки видео
  gallery.js                      карусель на «Подробнее»
  tariffs.js                      переключение тарифов + форма
css/, images/, fonts/             стили и ассеты (общие для всех страниц)
robots.txt                        правится вручную (см. ниже)
```

## Как запустить локально

Браузеры **запрещают** читать `data/*.json` при открытии файла напрямую (`file://`),
поэтому нужен любой мини-веб-сервер. Например, Python:

```powershell
py -m http.server 8000
# затем откройте http://127.0.0.1:8000/
```

Или расширение VS Code **Live Server** → «Go Live».

На боевом сервере всё работает как обычно (JSON отдаётся вместе с остальными файлами).

## Как адаптировать под другой проект

Почти всё делается редактированием `data/*.json` — HTML трогать не нужно.

### 1. `data/site.json` — глобальные данные

```jsonc
{
  "domain": "example.ru",                    // подставляется в юр. текст как {{site.domain}}
  "company": {
    "legalName": "ООО \"РОМАШКА\"",           // полное юр. название
    "copyrightName": "ООО \"Ромашка\"",       // имя в копирайте
    "brand": "Romashka",
    "inn": "0000000000",
    "ogrn": "0000000000000",
    "email": "info@example.ru"
  },
  "project": {
    "abbr": "ABC",                            // аббревиатура (R S M A на главной)
    "abbrRu": "АБВ",
    "name": "Полное название проекта",
    "heroWords": [                            // буквы/слова на главном экране
      { "letter": "A", "word": "lpha" },
      { "letter": "B", "word": "eta" },
      { "letter": "C", "word": "hamma" }
    ]
  },
  "assets": { /* пути к логотипам внутри images/ */ },
  "nav": [ { "label": "О продукте", "href": "index.html#about" } ],
  "socials": [ { "id": "vk", "label": "VK", "url": "...", "icon": "images/..." } ],
  "foundationUrl": "https://fasie.ru/",
  "footer": { "copyright": "© 2024 {{site.company.copyrightName}}", "companyLink": { } },
  "meta": { "home": { "title": "..." }, "about": { }, "tariffs": { }, "terms": { } }
}
```

### 2. Остальные файлы

* `data/home.json` — блоки «Особенности продукта», «Почему …?», видео, таблица тарифов, контакты.
* `data/about.json` — тексты страницы «Подробнее» и массив `gallery.images`.
* `data/tariffs.json` — цены/характеристики тарифов и подписи формы.
* `data/terms.json` — разделы юр. текста (`sections[].items[]`: `{"type":"p","html":...}` или `{"type":"ul","items":[...]}`).

## Синтаксис шаблонов (`js/data.js`)

На каждой странице в `<body>` задаются атрибуты:

* `data-page="home|about|tariffs|terms"` — какой файл `data/<page>.json` грузить;
* `data-root=""` (корень) или `data-root="../"` (подстраницы) — префикс пути до корня.

Поддерживается:

| Синтаксис | Назначение |
|---|---|
| `{{site.company.email}}` | подстановка значения (в тексте и в атрибутах) |
| `{{root}}images/logo.png` | путь до корня сайта |
| `<template data-repeat="page.tariff.rows" data-as="row">…</template>` | повтор блока |
| `data-if="row.basic"`, `data-if="it.type === 'p'"` | убрать элемент, если ложно |
| `data-html="it.html"` | вставить HTML из данных |

Токены можно вкладывать друг в друга: значение из JSON тоже может содержать `{{…}}`
(например `"copyright": "© 2024 {{site.company.copyrightName}}"`).

## Что ещё нужно поправить вручную

* **`robots.txt`** — статичный файл, домен и `Sitemap` вписываются руками.
* **Внешние скрипты** — jQuery/maskedinput (страница тарифов) и seamless-scroll-polyfill
  подключены с CDN.
* Отправка формы заявки в `js/tariffs.js` (`send()`) только показывает `alert` —
  подключите свой бэкенд/сервис.

## Примечания по миграции

* Общие картинки и шрифты были продублированы в каждой папке — теперь они в корне
  (`images/`, `fonts/`), ссылки в CSS подстраниц обновлены на `../../`.
* В исходных текстах остались опечатки, они сохранены «как есть», чтобы не менять контент:
  «Всенаправленные кроеса», «Потча» (исправлено на «Почта»). Поправьте при необходимости в JSON.
* Исходные страницы доступны в истории git.
